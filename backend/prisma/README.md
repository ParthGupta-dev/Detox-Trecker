# prisma/ — Prisma Schema and Migrations

This folder is populated in **Phase 5** when we add database persistence.

## What will belong here

- `schema.prisma` — the Prisma schema defining all models (User, ActivityLog, Goal, FocusSession)
- `migrations/` — versioned SQL migration files generated by `prisma migrate dev`

## What does NOT belong here

- Application code — that goes in `src/`
- Manual SQL edits to production — migrations are generated by Prisma and applied only by CI

## Key commands (Phase 5)

```bash
# Create a new migration after editing schema.prisma
npx prisma migrate dev --name describe-what-changed

# Apply pending migrations (used by CI in production)
npx prisma migrate deploy

# Regenerate the Prisma Client after schema changes
npx prisma generate

# Open the Prisma data browser
npx prisma studio
```

## Two URLs (see ARCHITECTURE.md 3.1)

- `DATABASE_URL` — pooled connection (Supavisor); used by the running app
- `DIRECT_URL` — direct connection; used by migrations only (`migrate deploy`)
